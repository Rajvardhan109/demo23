Layer 1 · Client side

What the student sees and taps.

The frontend extends the existing note-browsing UI with AI-aware surfaces: a personalized feed, a natural-language search bar, and a guided study path — built as React components on top of the current HTML/CSS/JS shell.

Dashboard additions

New sections on the student dashboard

Personalized feed

"Recommended for You"

A ranked feed generated by the hybrid recommendation engine, refreshed as the student interacts with more notes.

Quality signal

"Top Rated"

Notes surfaced purely by the quality scoring engine — ratings, downloads, and engagement, no manual curation.

Continuity

"Continue Learning"

Picks up where the student left off in a unit, reducing the friction of re-finding material mid-syllabus.

Search

NLP search bar

Accepts plain-language queries — "notes on recursion in DSA" — instead of requiring exact keyword matches.

Sequencing

Study path view

Renders the ordered unit-by-unit path generated by /study-path, with progress markers per topic.

Retention

Gap alerts

A lightweight nudge banner when a subject or unit has gone untouched, sourced from the gap-detection service.
