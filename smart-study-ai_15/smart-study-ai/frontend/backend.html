Layer 2 · Server + AI/ML

Where the ranking actually happens.

A REST API layer plus a hybrid recommendation engine: content-based filtering, collaborative filtering, quality scoring, and an NLP search module, all sitting between the frontend and the database.

API endpoints

REST API — existing and new

EndpointPurpose
POST /registerCreate a new student account.
POST /loginAuthenticate and start a session.
POST /upload-noteStore a note with subject, unit, title, and description metadata.
GET /get-notesFetch notes by subject, unit, or keyword.
GET /recommendReturn a ranked list of notes from the hybrid recommendation model for the logged-in student.
POST /rateSubmit a rating that updates both the note's quality score and the collaborative filtering matrix.
GET /search-nlpAccept a natural-language query and return semantically matched notes via sentence-BERT.
GET /study-pathReturn an ordered sequence of units based on syllabus structure and peer progression.
GET /gap-alertReturn subjects or units the student hasn't accessed recently, for the nudge banner.
AI / ML engine

Three models, blended into one ranking

Phase 1

Content-based filtering

TF-IDF and sentence embeddings run on note metadata to compute similarity vectors between notes — recommends by "what this note is about."

Phase 2

Collaborative filtering

Matrix factorization (SVD / ALS) applied to the user–note interaction matrix — recommends by "what similar students found useful."

Phase 3

Hybrid model

A weighted ensemble of both signals, tuned per user cohort, is what actually serves /recommend.

NLP search

Semantic search

A fine-tuned BERT / sentence-transformers model powers /search-nlp, matching intent rather than exact words.

Request flow
Frontend request→ Backend API (Node.js / Flask)→ AI / ML engine→ Feature store (embeddings + interactions)→ Ranked response

Recommendation service

Wraps the hybrid model; called by /recommend on every dashboard load.

Quality scoring service

Aggregates ratings, download frequency, and engagement metrics into a single rank-able score.

NLP module

Embeds incoming queries and performs nearest-neighbor lookup against note embeddings via FAISS.

Retraining job

Runs daily or weekly on updated interaction data to keep the models current.

Tech stack
API framework

Node.js (Express) or Python (Flask) serving the REST endpoints above.

ML libraries

scikit-learn for classical models, TensorFlow / PyTorch for deep components.

NLP

Hugging Face Transformers with a Sentence-BERT / multilingual BERT checkpoint.

Vector search

FAISS for fast nearest-neighbor lookup over note embeddings.

DevOps

Git/GitHub for version control, Postman for endpoint testing, Docker for containerized deployment.
